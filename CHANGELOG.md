# Changelog

## 13.2-0 (2026-11-19)

- First release: Zulip Server 13.2 (`ghcr.io/zulip/zulip-server:13.2-0`), PostgreSQL 14 (`zulip/zulip-postgresql:14`), RabbitMQ 4.2.9, Memcached 1.6.45 and Railway's Redis.
- The first boot creates an organization and its owner from `ZULIP_ADMIN_EMAIL` and a generated `ZULIP_ADMIN_PASSWORD`.
